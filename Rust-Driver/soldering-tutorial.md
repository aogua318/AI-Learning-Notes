## 1. 为什么写驱动的人必须会焊接

三个理由，按重要性排序：

1. **实物项目的最后一公里全是焊接**。面包板加杜邦线能让 PC 认出摇杆，但装进外壳、走线、固定按键，绕不开焊点。不会焊接 = 永远停在"洞洞板原型"阶段。
2. **焊接是理解"驱动"的身体记忆**。你写的每一行 GPIO 代码，最终都要变成一根真实的导线连接到芯片引脚上。焊过一次按键到 Pico 的 GPIO，"引脚复用""上拉电阻"这些词对你不再是抽象概念。
3. **排查硬件故障的基本功**。运维现场遇到设备接触不良，看得懂焊点虚焊，就能判断是硬件问题还是软件问题。

技能分级：**through-hole 焊接是一小时技能**，比所有权模型好懂多了。贴片（SMD）焊接是另一个世界，本文不碰——你的项目（Pico、按键、杜邦线）全部是 through-hole。

## 3. 焊接的物理原理：传热比锡重要

新手最大的误解：焊接 = "用锡把两个东西粘起来"。错。焊接的本质是：

> **烙铁加热焊盘和元件引脚 → 焊锡丝接触被加热的金属 → 锡熔化后浸润金属表面 → 冷却后形成金属间合金。**

关键推论，直接决定你怎么操作：

1. **烙铁的热量要传给焊盘和引脚，不是传给锡**。所以标准手法是"烙铁先接触焊盘和引脚，再把锡丝送到烙铁与焊盘的接触点"，而不是"用烙铁熔一大滴锡再抹上去"。
2. **浸润（wetting）** 是焊点合格的唯一标准：熔化的锡应该像水渗进海绵一样铺展开，形成光滑的凹液面（ concave ）。如果锡结成灰疙瘩或水珠状滚在那里，就是没浸润——虚焊的前兆。
3. **时间窗口：每个焊点 1–3 秒**。时间太短，温度不够，锡不浸润；太长，烫坏元件（LED、Pico 上的芯片对热敏感）或让焊盘起皮脱落。
4. **助焊剂是清洁工**。金属表面有氧化层，锡不沾氧化层。松香助焊剂在加热时清除氧化层，让锡直接接触干净金属。这就是为什么旧焊点（发灰、不沾锡）要先加助焊剂或干脆刮干净重焊。

## 4. 七步实操：焊一个完美的焊点

以一个电阻焊到洞洞板为例（引脚穿过焊盘孔）：

1. **预热烙铁**：插电等 3–5 分钟。检验方法：送一点锡到烙铁头，锡应该立刻熔化并挂在上面（挂锡）。不挂 = 没热好，或烙铁头氧化了（用海绵加锡擦拭，不行就用湿报纸擦）。
2. **同时接触**：烙铁头斜着，**同时贴住焊盘（铜箔）和元件引脚**——两个都要热。这是全流程最重要的一步，只热一边必出虚焊。
3. **送锡**：另一只手把焊锡丝送到烙铁与焊盘的接触点（不是送到烙铁头顶端）。锡受热熔化，流入焊盘孔，包住引脚。
4. **看量**：一个标准 through-hole 焊点的锡量：刚好填满焊盘孔，在引脚根部形成一个微微下凹的圆锥。孔被填满、锡量不溢出即可。宁少勿多，多了流到别处就是连锡。
5. **先撤锡丝，后撤烙铁**：看到锡浸润开了，先移开锡丝；保持烙铁接触约半秒，让锡充分流动，然后先撤烙铁。
6. **凝固时不许动**：保持板子和元件静止几秒，锡从液态到固态会经历"糊状"阶段，这时候一晃，焊点就是灰白色的疏松疙瘩——虚焊。
7. **剪脚**：焊点冷却后，用剪线钳把引脚多余的线剪掉（保留约 1–2 mm）。

**自检三问**（焊完每个点问自己）：

- 表面是光滑发亮的吗？（灰白 = 糊状期动了，或温度不够）
- 锡把引脚和焊盘**都**包住了吗？（半包 = 只热了一边）
- 锡量合适吗？（能隐约看到引脚轮廓，而不是一个银球）

## 5. 练习方案：焊什么练手

不要第一次就焊按键——按键贵，焊废了心疼。按这个顺序烧掉你的练习板：

1. **焊一排电阻**（10 个起步）：直着焊、斜着焊、躺平焊。目标是十连发的光滑圆锥。焊废了不心疼，还能用吸锡器练拆。
2. **焊杜邦线到洞洞板**：练"粗线焊细盘"，同时产出你以后要用的转接板。
3. **焊一个拆机的旧件**（旧充电器、旧路由器上剪下来的元件）：接触真实世界的氧化焊盘，体验"助焊剂救命"时刻。
4. **加练：拆**。用吸锡器把第 1 步焊的电阻全拆下来。会焊不会拆，返工时只能靠吼。

熟练标准：连续焊 20 个点，90% 以上光滑发亮、不需要返工。达到这个水平再碰 Pico——Pico 是焊坏了要心疼的。

## 6. 常见缺陷与修复

| 缺陷 | 长什么样 | 原因 | 修复 |
|---|---|---|---|
| 虚焊（冷焊） | 灰白、疏松、不亮 | 温度不够，或凝固时晃动了 | 加助焊剂，重新加热重焊 |
| 锡球 / 不浸润 | 锡结成球滚来滚去 | 焊盘氧化，或只热了锡没热盘 | 刮干净焊盘，加助焊剂，烙铁同时贴盘和脚重焊 |
| 连锡（短路） | 两个不该连的焊点被锡连上 | 锡量失控 | 烙铁头快速扫过连锡处把锡带走，或用吸锡器 |
| 焊盘起皮 | 铜箔从板上翘起来 / 脱落 | 温度过高 + 时间长 | 预防为主：控制 1–3 秒。已起皮就引一根线搭到元件脚上连通 |
| 烫坏元件 | LED 不亮了，芯片发烫 | 耐热差的元件焊太久 | 焊 LED / 芯片时加快速度，或先用镊子夹住引脚"散热桥" |

**黄金修复原则**：任何不满意的焊点，先加锡再加热重焊（"先润后修"），比干加热或硬刮都有效——新熔的锡会带走部分氧化物。

## 7. 安全守则

1. **烫伤是第一风险**。烙铁头 300°C 上下，碰到手背一秒就是水泡。铁架是它的停车位，不焊就放回去，绝不随手放桌上——这是每个被烫过的人都懂、每个没被烫过的人都会犯的错。
2. **有铅焊锡**：含铅，但日常焊接吸入风险低。规则：焊完**洗手**（铅从口入），别在焊台上吃东西。想彻底安心买无铅锡，但无铅熔点高、难焊，新手体验差，建议先用有铅练手。
3. **通风**。助焊剂加热有烟，不致命但难闻。窗口边操作，或装个小排风扇。别对着脸吸。
4. **烫坏桌面**。烙铁架下垫块木板或耐热垫。悬空插拔烙铁前，先确认它躺在铁架上。
5. **剪脚的碎屑会弹**。剪线钳剪引脚时，用手指挡一下飞溅的铜脚，掉进眼睛里不是玩笑。
