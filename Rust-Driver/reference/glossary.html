Rust 语言核心

所有权（ownership）
Rust 的核心规则：每个值有且只有一个所有者，由所有者在作用域结束时通过 Drop 清理。
避免：归属权、财产权
所有者（owner）
持有某个值并承担其 Drop 责任的变量；所有权可以转移（move），但任何时候只有一个。
避免：主人、属主（口语教学可用"主人"，书面一律用"所有者"）
移动（move）
所有权随赋值或传参转移到新变量，旧变量立即失效；堆数据本身不动，动的是栈上的所有权三元组。
避免：转移、搬运、交接
拷贝（Copy）
类型实现的标记 trait；赋值时按位复制一份，原变量仍然有效。与 Drop 互斥。
避免：复制（泛指）、clone
销毁（Drop）
所有者离开作用域时自动执行的清理动作，通常释放堆资源；不能手动调用 .drop()，提前释放用 std::mem::drop。
避免：释放、回收、析构（C++ 语境词）
引用（reference）
&T / &mut T，不获取所有权的访问凭证；同一时间可存在任意多个 &T，或恰好一个 &mut T。
避免：指针（裸指针 *const / *mut 另有所指，不可混用）
可变绑定（mutable binding）
用 mut 声明的变量，其值可以被修改；默认绑定不可变。
避免：变量（不修饰时一律指不可变绑定）
遮蔽（shadowing）
用同名 let 绑定新值，旧绑定被永久覆盖，可顺便更换类型；与"重新赋值"是两回事。
避免：重新赋值、覆盖
尾表达式（tail expression）
函数体最后一个不带分号的表达式，它的值就是函数的返回值；加分号则变成语句、值被丢弃。
避免：隐式 return、最后一行

嵌入式与硬件

固件（firmware）
烧写在 MCU 内部 Flash 中、上电即运行的程序；没有操作系统，你的代码就是全部。
避免：单片机程序、裸机代码
MCU（微控制器）
把 CPU、内存、外设集成在一颗芯片上的微型计算机，本项目指 Raspberry Pi Pico 上的 RP2040。
避免：单片机、芯片（单独用时指代不明）
HAL（硬件抽象层）
把寄存器操作包装成安全函数库的中间层；本项目用 rp2040-hal，它是 embedded-hal traits 在 RP2040 上的实现。
避免：库、驱动（HAL 不是内核驱动）
USB HID（人机接口设备类）
USB 的设备类标准，键盘、鼠标、游戏摇杆都属此类；操作系统自带通用驱动，设备只需按规范上报数据。
避免：USB 协议（HID 是 USB 之上的一个类规范）
UF2 烧录
把 Pico 按住 BOOTSEL 插 USB，让它以 U 盘形式出现，把 .uf2 文件拖进去即完成烧录的方式。
避免：刷机、拷程序
through-hole（直插元件）
引脚穿过电路板过孔再焊接的元件形态；按键、排针、杜邦线都是，入门焊接只练这种。
避免：插件、THT（中文语境不常用英文缩写）

工具链

rustup
Rust 官方工具链管理器，负责安装和切换 Rust 编译器与交叉编译目标。
避免：Rust 安装包（Rust 没有传统意义上的"安装包"）
thumbv6m-none-eabi
RP2040 的 Cortex-M0+ 核心对应的交叉编译目标名；编译固件时 cargo build --target thumbv6m-none-eabi 的 target 就是它。
避免：ARM 编译、裸机目标（指代模糊）
no_std
不依赖标准库、只依赖 core 的运行环境；固件和 eBPF 程序都活在里面，没有堆分配器和文件系统。
避免：无库、裸 Rust
CO-RE（Compile Once, Run Everywhere）
eBPF 的一次编译、多内核版本运行的机制；aya 库支持，第二阶段接触。
避免：一次编译到处运行（字面直译，不用于术语）
