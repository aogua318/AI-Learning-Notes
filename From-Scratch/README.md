# From-Scratch：从零手搓系列

不借助第三方库，从算法、协议、文件格式的第一手原理出发，用 Python 标准库完整实现，并理解每一行代码为什么这么写。

## 系列目录（按依赖顺序阅读）

| 顺序 | 教程 | 主题 | 产物 |
|---|---|---|---|
| 1 | [md5-tutorial.md](md5-tutorial.md) | MD5 算法原理（RFC 1321）→ 纯 Python 手写 → 单元验证 → CLI → Cython 编译为 C → 原生 exe | 约 1~2 MB 的 `md5.exe`（对比 PyInstaller 打包的 10~30 MB） |
| 2 | [bt-tutorial.md](bt-tutorial.md) | SHA-1 原理 → bencode 编解码 → .torrent 解析 / infohash / 分块校验 / 种子制作 → 磁力链解析与生成 → DHT 最小实现 | 种子校验 / 制作 + 磁力链工具 CLI |
| 3 | [mp3-tutorial.md](mp3-tutorial.md) | 感知编码原理 → ID3v2 + 帧流 + ID3v1 字节级结构 → 帧解析器 → 最小合法 MP3 生成器 | 可运行的帧解析器与 MP3 合成器 |

## 三篇之间的关系

- **第 1 篇是地基**：建立「手搓一个算法 → 用标准测试向量验证 → 打包成原生 exe」的完整方法论；
- **第 2 篇迁移战场**：把同一套方法应用到 BT 生态——磁力链和 .torrent 用的是 SHA-1，不是 MD5，从 SHA-1 重新手搓起；
- **第 3 篇换个维度**：前两篇是「二进制与协议」，本篇回答「MP3 为什么能存下音乐」，并给出人人可写的帧解析器和最小合法 MP3 生成器。

## 运行方式

- Python 部分全程只用标准库，无需安装第三方依赖；
- 代码完整内嵌在教程中，可整段复制运行；
- 第 1 篇打包 exe 的环节需要 Cython 和 C 编译器（MSVC / MinGW），教程内有安装说明。
