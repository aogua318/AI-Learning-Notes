# NOTES.md — 日语教学工作区工作笔记

## 用户背景（来自 2026-10-19 咨询会话）

- 目标：日常旅游交流水平的日语，出行时间未定（半年以上），稳扎稳打
- 时间：每天 1 小时以上
- 基础：会五十音或以前学过；常看动漫日剧，有被动听力输入，开口少
- 选择：按 Rust-Driver 模式搭建 HTML 互动课教学空间（用户主动选了"分课学习"）

## 课程设计原则（据此定制）

- 场景优先、整句优先；语法只学场景需要的最小碎片
- 听力起步可以略高（有浸泡基础），但五十音仍需一次快速确认课
- 每课一个明确的可带走成果 + 间隔重复任务（Anki），重 storage strength 而非刷课 fluency
- 沉浸法风险：被动输入多的人容易"听得懂说不出"——课程必须逼开口（跟读、模拟场景、口头自测）

## 已确认的关键决策（2026-10-19）

1. 任务升级为「深度自由行」（MISSION.md 已改）：救场句、抓关键词听力、应急场景进验收标准。
2. 场景取材：**都市优先**（东京/大阪/京都的胡同、市场、家族小店、立饮屋），地方交通/乡村作进阶模块。
3. 语法讲法：**编程类比嵌入场景课**——助词≈关键词参数、动词变形≈函数包装、です/ます≈正式接口；每处标注「类比仅作助记」，优先保开口，不当理解任务。
4. 听力材料：**真实语料为主 + 生肉片段加练**（不当验收标准）。
5. 交付节奏：**先写前三课（0002–0004）试水**，用户刷完反馈后再写后续。
6. 十课大纲已定（0002–0011）：五十音确认 / 救场句 / 数字价格日期 / 购物 / 餐厅 / 交通问路 / 酒店民宿 / 应急就医 / 听力专项 / 模拟深度游日。

## 深度游与生肉讨论（2026-10-19，结论已确认：升级为深度自由行）

用户问：深度自由行这个程度够用吗？生肉生放送呢？

评估结论（已告知用户）：
- 深度自由行：事务性沟通够，整体不够从容。缺口在「听」（对方自然语速的长回应）、「计划外」（应急 / 误车 / 就医）和非事务性闲聊。当前课程只有「你说」没有「你听」。
- 生肉生放送：不够，差一个量级（日常动漫大致 N3 起头、N2 舒服；生放送 N1 也别强求）。差距在听力词汇量、口语缩约形（〜てる / 〜ちゃう / 助词脱落）、自然语速。但生肉可当训练材料，与深度游听力共享同一底层能力（听力词汇 / 缩约形 / 抓关键词）。

若用户批准「升级为深度自由行」，课程调整方案（已拟定，待执行）：
1. 救场句提前教：もう一度お願いします、ゆっくりお願いします、紙に書いてもらえますか、英語／中国語が話せますか
2. 听力目标改为「抓关键词」（数字 / 时间 / 地点 / はい・いいえ），每个场景课加「对方可能怎么回你」的听力输入
3. 应急与地方交通加重：就医、落とし物、误车改签、预约制巴士、末班车
4. 生肉支线：用动漫 / 生放送片段做抓关键词训练，不当验收标准
