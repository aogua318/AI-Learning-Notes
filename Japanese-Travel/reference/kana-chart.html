じ = ぢ、ず = づ（读音无区别，写哪个都不算错）。

组合规则

  • 小写 っ：停顿一拍，后一个辅音双写。例：きって（邮票）≠ きて（来）。
  • 长音符 ー（片假名中）：前一个音拉长一拍。例：コーヒー = ko-o-hi-i。
  • 拗音：辅音 + 小写 や ゆ よ，拼成一拍。例：きょう（今日）= き + ょ 一拍，不是两拍。
  • 助词变读：は → wa、へ → e、を → o（只当助词时）。

3 秒训练法

  1. 闭眼点一个格子（或让家人指），3 秒内读出。
  2. 秒答的放过；超过 3 秒的进 Anki「假名认读」牌组，过关就删。
  3. わ/れ/ね、ぬ/め、さ/ち/き 做对比卡：同题出现，逼你区分，永不单独出现。
  4. 日常补料：便利店招牌、App 图标、零食包装、动漫片头名单——真日语优先于练习纸。
