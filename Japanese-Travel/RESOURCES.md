# 日语旅游生存 Resources

> 标注 ✅ 的条目为 2026-10-19 实际访问核实过内容；未标注的为高可信来源，但本环境无法联网搜索，使用前请手动抽查最新状态。

## Knowledge

- [Tofugu: Learn Hiragana（平假名记忆法）](https://www.tofugu.com/japanese/learn-hiragana/) ✅
  用图像助记把字形和读音挂钩，先认读后书写，配套测验与练习纸。用途：五十音确认课的主参考；第一课的"先求会读不求会写"思路与它一致。
- [NHK World Japan「简明日语」](https://www.nhk.or.jp/lesson/)
  日本国际广播机构出品的免费日语课程，场景对话导向，每课附音频与 PDF，覆盖旅游高频场景。用途：听力跟读的主材料。
- [《大家的日语》Marugoto（日本国际交流基金会）](https://www.marugoto.org/)
  JF 官方教材，"用日语做事"的沟通导向，初级 I 覆盖旅游生存所需。用途：系统教材备选；课程的语法点可回查原文。
- [Genki（Japan Times）](https://genki.japantimes.co.jp/)
  北美大学主流日语教材，讲解清晰、练习扎实。用途：备选主教材；比 Marugoto 更学院派。
- [JapanesePod101](https://www.japanesepod101.com/)
  场景化音频课库，可按场景（旅行 / 点餐 / 购物）检索。用途：碎片时间磨耳朵 + 场景句补充。
- [Anki（间隔重复记忆软件）](https://apps.ankiweb.net/)
  开源间隔重复系统，本工作区记忆训练的主力工具。用途：每课的句卡牌组；长期 retention 靠它，不靠课上那点 fluency。
- [Jisho.org（在线日语词典）](https://jisho.org/)
  带假名读音的日英词典，查词第一站。用途：遇到生词先查这里，看读音和真实例句。
- [换乘案内 / Jorudan World](https://world.jorudan.co.jp/mln/en/)
  日本交通换乘查询（英文界面）。用途：第三课交通场景的配套工具，顺便学读车站名与线路名。

## Wisdom (Communities)

- [r/LearnJapanese](https://www.reddit.com/r/LearnJapanese/)
  最大的日语学习社区，提问前先读 wiki。用途：学习方法与资源选择的现实检验场。
- [Japanese Language Stack Exchange](https://japanese.stackexchange.com/)
  高信噪比问答，适合"为什么"类问题。用途：语法细节的权威追问点。
- HelloTalk / Tandem（语言交换 App）
  与日本人文字 / 语音互换。用途："模拟旅游日"之前，找真实日本人练手的场地（用户未表示排斥，按需推荐）。
