# Network — 计算机网络机制原理与排障

> 教学工作区（teach）：HTML 互动课为主线，配套自有真机实验。使命与约束详见 [MISSION.md](MISSION.md)。

## 学习目标

从"会配"到"懂为什么"。以华为设备为操作面，建立以太网交换、IP 网络层、传输层、路由协议、应用服务各层的协议机制级理解；遇到故障能从原理定位，而不是逐条试配置。同时为 Rust-Driver 第二阶段"USB 网络检测盒"（ARP 扫描、网段发现）提供网络知识前置。

## 实验环境（eNSP 模拟器，公司设备红线不碰）

- **eNSP**（华为官方免费模拟器，Windows 原生）：S 系列交换机（S5700 等）、AR 系列路由器都以本地进程运行，2–4 台设备很轻量；USG6000 等少数设备需要 VirtualBox 虚拟机
- **Wireshark**：eNSP 拓扑图上右键链路 →「开始抓包」直接调起，绑定到模拟接口，能看到真实的 BPDU / ARP / OSPF 报文
- 下载需华为账号（免费）：华为企业业务支持 → 工具 → eNSP
- 拓扑规模约束：本课程实验按 2–4 设备设计；10+ 设备的大拓扑（如多区域 OSPF 全网）不做或拆成小拓扑分次验证
- 模拟器的独特优势：能故意制造故障（拔线、配错、成环）复现排障场景，弄坏了一键重启设备即可，零成本零风险
