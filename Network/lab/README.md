# eNSP 实验环境搭建

本目录是 Network 课程的实验手册。所有实验在 **eNSP**（华为官方免费模拟器）里完成，不碰公司设备。

## 1. 下载与安装

1. 访问华为企业业务支持（support.huawei.com）→ 工具 → eNSP，用华为账号登录下载（免费）。
2. 安装 eNSP。它会连带安装 **VirtualBox**（少数设备如 USG6000 防火墙需要虚拟机运行；S5700 交换机和 AR 路由器以本地进程运行，不需要）。
3. 安装 **Wireshark**（eNSP 的抓包功能调用它）。安装时勾选 Npcap/WinPcap 组件。

> 版本提示：eNSP 有多个版本（V100R001C10、V100R002C00 等），设备库与 VRP 版本略有差异。课程命令以设备自带 `?` 帮助为准，不同版本输出格式可能有小差别，不影响机制理解。

## 2. 基本操作

| 操作 | 方法 |
|---|---|
| 添加设备 | 左侧设备面板把 S5700 拖进拓扑区 |
| 连线 | 点「设备列表」上方的连线工具，选 **Copper（铜线）**，依次点两个设备的端口 |
| 启动设备 | 右键设备 → 启动；首次启动要等 1–2 分钟加载 VRP |
| 登录命令行 | 双击设备，弹出 CLI 窗口（无需密码，直接回车） |
| 重启设备 | 右键设备 → 重启/关闭再启动 |
| 抓包 | 右键一条**链路** → 开始抓包，Wireshark 自动打开并绑定该链路 |

## 3. 常用视图命令速查

```
display version            # 看 VRP 版本与设备型号
display device             # 看设备面板状态
display interface brief    # 看所有接口状态与 IP
display ip routing-table   # 看路由表
display stp brief          # 看 STP 选举结果（第一课用）
```

## 4. 注意事项

- **拓扑规模**：本课程实验按 2–4 台设备设计。设备开多了电脑会卡，10+ 设备的大拓扑不要一次全开。
- **保存拓扑**：eNSP 拓扑文件（.topo）建议存到本目录或课程目录，实验手册里会注明每课需要的拓扑。
- **抓包权限**：Wireshark 抓 eNSP 链路需要 Npcap；若抓包按钮点了没反应，检查 Wireshark 安装时是否勾选了 Npcap。
- **命令帮助**：任何命令记不准，在 CLI 里输入命令前几个字母加 `?`，设备会列出补全与说明——这是网络工程师的标准做法，也是本课程命令的最终依据。
