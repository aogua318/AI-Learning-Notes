# Mission: 计算机网络机制原理与排障

## Why
用户是网络运维工程师（华为设备为主，公司设备黑盒），日常操作交换机/路由器但停留在"会配"层面。目标是建立协议机制级理解——看到配置能说出背后的原理，遇到故障能从原理判断而非凭经验猜。同时为 Rust-Driver 第二阶段"USB 网络检测盒"（ARP 扫描、网段发现）提供网络知识前置。

## Success looks like
- 能解释日常操作背后的机制：STP 为什么阻塞这个端口、OSPF 邻居为什么起不来、TCP 重传在什么条件下发生
- 遇到 ping 不通 / 环路 / 邻居震荡等故障，能按分层模型从原理定位，而不是逐条试配置
- 在 eNSP 实验环境里独立搭拓扑完成机制实验，并用 Wireshark 抓包验证
- 检测盒项目所需的网络知识（ARP、UDP 广播、子网划分）就绪

## Constraints
- 每周 5–10 小时，与 Rust-Driver 主线并行拆分
- 实验环境：eNSP（华为官方免费模拟器，Windows 原生）+ Wireshark 抓包（eNSP 右键链路直接调起）；电脑能带简单拓扑（2–4 设备），10+ 设备的大拓扑不做或拆小
- 公司设备完全黑盒：所有实验只在自有硬件上进行
- 英语水平有限：术语保留英文原文并附中文对照
- 课程形态：HTML 互动课（每节 15–20 分钟，一个知识点 + 页面内互动练习），沿袭 Rust-Driver / Git 工作区模式
- 基础定位（2026-10-20 六题诊断）：会配 VLAN/trunk/STP 模式，ARP 网关模型与 TCP 三次握手（含"为什么不是两次"）理解正确，分层排障有直觉；机制缺口在 STP 内部过程、OSPF 邻居条件等。课程从机制缺口切入，不从零教起

## Out of scope
- 考证应试（HCIA/CCNA 大纲只作路线图参考，不作目标）
- BGP 深入、MPLS/VPN、IPv6 专题、无线专题
- 网络安全攻防
- 网络自动化（Python/Ansible）——原理打底后的第二阶段再评估
